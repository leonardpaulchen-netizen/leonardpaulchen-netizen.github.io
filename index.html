Myko Leo Social

Myko Leo Social ist ein privates Werkzeug, mit dem der Betreiber Inhalte auf seinen eigenen Social-Media-Kanälen (YouTube, Instagram, Facebook, TikTok) veröffentlicht und plant. Es wird ausschließlich vom Betreiber selbst genutzt.

Datenschutzerklärung · Nutzungsbedingungen · Datenlöschung

Datenschutzerklärung

Stand: 24. November 2026

  • Welche Daten: Über die offiziellen Schnittstellen (YouTube Data API, Meta Graph API für Facebook und Instagram, TikTok Login Kit und Content Posting API) greift die Anwendung nur auf die Konten des Betreibers zu: Kanalinformationen, eigene Videos und deren Metadaten sowie Zugriffstokens.
  • Zweck: Hochladen, Planen und Verwalten eigener Inhalte. Es findet keine Analyse, kein Profiling und keine Werbung statt.
  • Speicherung: Zugriffstokens werden nur lokal auf dem Rechner des Betreibers gespeichert. Es gibt keinen Server und keine Datenbank.
  • Weitergabe: Daten werden nicht verkauft und an niemanden weitergegeben, außer an die jeweilige Plattform selbst, um die gewünschte Aktion auszuführen.
  • Widerruf: Der Zugriff kann jederzeit widerrufen werden: Google unter myaccount.google.com/permissions, Facebook/Instagram unter Facebook → Einstellungen → Business-Integrationen, TikTok in der App unter Einstellungen → Sicherheit → Apps und Dienste. Lokale Tokens werden dann gelöscht.
  • Google API Services: Die Nutzung von Daten aus Google APIs entspricht der Google API Services User Data Policy, einschließlich der Limited-Use-Anforderungen. Es gelten außerdem die YouTube-Nutzungsbedingungen und die Google-Datenschutzerklärung.
  • Meta (Facebook, Instagram): Es gelten die Meta-Plattform-Nutzungsbedingungen und die Meta-Datenschutzrichtlinie. Daten aus Meta-Schnittstellen werden nur zum Veröffentlichen eigener Inhalte verwendet.
  • TikTok: Es gelten die TikTok-Nutzungsbedingungen und die TikTok-Datenschutzrichtlinie. Verwendet werden nur Basis-Profildaten (Anzeigename) und das Hochladen eigener Videos.
  • Kontakt: über die im YouTube-Kanal oder auf den Social-Media-Profilen von „Myko Leo“ angegebene Kontaktmöglichkeit.

Nutzungsbedingungen

Die Anwendung ist nicht öffentlich verfügbar und wird nur vom Betreiber für seine eigenen Konten genutzt. Mit der Nutzung gelten die Bedingungen der jeweiligen Plattformen, darunter die YouTube-Nutzungsbedingungen, die Meta-Plattform-Nutzungsbedingungen und die TikTok-Nutzungsbedingungen. Es werden nur eigene Inhalte veröffentlicht; Daten anderer Nutzer werden nicht abgerufen.

Anleitung zur Datenlöschung

Die Anwendung speichert keine Daten auf einem Server. Um alle Daten zu löschen: 1) Zugriff der App „Myko Leo Social“ in den Einstellungen der jeweiligen Plattform entfernen (Links unter „Widerruf“). 2) Der Betreiber löscht daraufhin die lokal gespeicherten Tokens. Anfragen zur Löschung können jederzeit über die oben genannte Kontaktmöglichkeit gestellt werden.
